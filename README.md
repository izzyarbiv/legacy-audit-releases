# Legacy Audit — releases

Installers and update manifests for the Legacy Audit desktop app, published by Faberstack for Legacy Consulting.
Installed copies of the app check here for new versions and update themselves.

This repository holds **release files only**: no source code, no audit data, no client information.

**Windows:** download the latest `Legacy-Audit-Setup-<version>.exe` from the Releases page.
Windows may show "Windows protected your PC" (the installer is not code-signed yet): click *More info*, then *Run anyway*.
